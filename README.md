# sotsuron_sekine

## コード紹介

### make_image

- データを画像に変換するためのコード
  - ファイル名ごとに対応している
  - 同じ部分と Pcap ファイル用の異常ラベルはそれぞれ same.py と label.py にある

### test_code

- 画像を GPU サーバ上で動かしたコード
  - 千葉工業大学の GPGPU サーバで動くようにしてあるのでどこでも動くわけではないです
  - それぞれのモデルごとにファイルを分けています

### Dockerfile

- 大学の GPU サーバで動かす用です

### .devcontainer

- 画像用のコードだけを動かすための仮想環境です
